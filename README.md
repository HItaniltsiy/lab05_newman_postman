## Спецификаци

| # | Туршилт / setup | Хүлээгдэх статус | `result` |
|---:|---|---:|---|
| 1 | Идэвхтэй оюутан, шаардлагатай хичээлийг үзсэн, хичээл байна | 201 | `OK` |
| 2 | Оюутны ID байхгүй | 200 | `ERROR_NO_STUDENT` |
| 3 | Оюутан идэвхгүй | 200 | `ERROR_INACTIVE_STUDENT` |
| 4 | Хичээлийн ID байхгүй | 200 | `ERROR_NO_COURSE` |
| 5 | Урьдач хичээлээ үзээгүй | 200 | `ERROR_PREREQUISITES` |
| 6 | `courseID` талбар дутуу | 400 | `ERROR_BAD_REQUEST` |
| 7 | Урьдач нөхцөлгүй хичээл, хоосон жагсаалт | 201 | `OK` |
| 8 | Урьдачийн заримыг үзсэн (`CS201` үзсэн, `CS202` дутуу) | 200 | `ERROR_PREREQUISITES` |`n| 9 | Давхар алдаа: оюутан идэвхгүй, хичээл байхгүй | 200 | `ERROR_INACTIVE_STUDENT` |

Давхар алдааны жишээ нь сервер эхлээд оюутны төлөвийг, дараа нь хичээлийг шалгадаг тул `ERROR_INACTIVE_STUDENT` буцаана.

## Newman үр дүн

| Ажиллуулалт | Командын exit code | Assertions (executed / failed) |
|---|---:|---|
| PASS (`results/newman-pass.txt`) | 0 | 19 / 0 |
| зориудын FAIL (`results/newman-fail.txt`) | 1 | 19 / 1 |
| Сервер унтарсан DOWN (`results/newman-down.txt`) | 1 | 19 / 19 |

PASS/FAIL/DOWN бүрийн Newman-ийн бүтэн гаралт `results/` дотор бий. DOWN үед `ECONNREFUSED` нь холболтын түвшний интерфейсийн алдаа; хариу ирээгүй тул oracle ажиллаж шалгагдаагүй.

## Дүгнэлт

Тест дизайны таван алхмаас сонголтуудын хослолыг багасгаж төлөөлөх утга сонгох нь хамгийн их бодол шаардсан. Идэвхгүй оюутан ба байхгүй хичээлийг хамтад нь өгсөн давхар алдаанд сервер оюутны төлөвийг түрүүлж шалгав. Ингэснээр энэ хослол `ERROR_INACTIVE_STUDENT` буцаахыг тогтоов. Урьдачгүй хичээлд хоосон `coursesTaken` байсан ч бүртгэл амжилттай болдог. Бүртгэлийн амжилтыг статус болон `result`-ээр шалгасан. Хуримтлагдах `registrationID`-ийн яг утгыг шалгаагүй. Тестүүд заасан API хариунаас зөрүү илрүүлээгүй. DOWN туршилт нь API-ийн хариуны oracle-оос тусдаа холболтын алдааг харуулсан.
