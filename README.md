## Дүгнэлт

Таван алхмаас сонголтын хослолыг бодит төлөөлөх утгаар гаргах нь хамгийн их бодол шаардсан. Оюутан болон хичээл хоёулаа байхгүй үед сервер `ERROR_NO_STUDENT` буцаав. Идэвхгүй оюутан ба байхгүй хичээлийн хослолд `ERROR_INACTIVE_STUDENT` буцсан. Ингэснээр формат, оюутан, төлөв, хичээл, урьдач нөхцөлийн шалгах дарааллыг тогтоов. Оюутан байхгүй үед үзсэн хичээлийн сонголт утгагүй, хичээл байхгүй үед урьдач нөхцөлийг шалгах боломжгүй. Зарим урьдачийг үзсэн үед дутуу `CS202` хичээл `missing` массивт зөв гарсан. 23 PASS assertion шаардлагатай хариунуудтай зөрөөгүй тул согог илрүүлээгүй. Давтан бүртгэлийн дүрэм зааварт байхгүй учраас түүнийг согог гэж дүгнээгүй. Зориудын FAIL ба DOWN үр дүн нь oracle болон холболтын алдааг тус тус харуулав.
